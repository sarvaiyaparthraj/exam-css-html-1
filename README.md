exam-1 Pure Cycles Website (HTML + CSS + Table Layout) This project is a simple front-end website layout created using pure HTML tables and external CSS. The design is based on a sample bicycle e-commerce homepage layout.

📁 Project Structure /project-folder │ ├── index.html # Main HTML file (table based layout) ├── style.css # External stylesheet └── images/ # Image assets (optional folder)

📄 Description The website contains the following sections:

✔ Header Logo Navigation menu Search & Cart icons ✔ Hero Banner Large main image (Uses: /mnt/data/Pure Bicycle.png or your custom image) ✔ Featured Bikes Section 4 product blocks (table layout) “View All” button ✔ Shop By Category 4 category images ✔ YouTube Video Embed Responsive iframe inside table ✔ Footer Shop, Connect, About columns Email subscription field 🚀 How to Use Download the project folder. Make sure both files are inside the same directory: index.html style.css Open index.html in any web browser. 🖼 Images You can replace hero or product images by updating the  tag paths in index.html.
